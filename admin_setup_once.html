Tips:
  • If your contract is onlyOwner for mint, connect with the deployer/owner wallet.
  • If mint is payable, set ETH per mint (e.g., 0.01) before trying.
  • If mint requires tokenId, set a sensible Token ID base; it will mint IDs base + i.
  • If there’s a sale flag (e.g., saleActive/paused), make sure it’s enabled in your contract.
